# سجل تشخيص My TV Launcher

يسجل التطبيق الأخطاء في ملف دائم خارج ملف APK، لأن APK يصبح للقراءة فقط بعد تثبيته ولا يمكن للتطبيق الكتابة داخله. يعمل السجل على Android 7 ويحتفظ بآخر **512 كيلوبايت** من الأحداث، ثم ينقل السجل السابق إلى ملف احتياطي لمنع امتلاء مساحة الجهاز.

| العنصر | التفاصيل |
|---|---|
| سجل التطبيق الحالي | `Android/data/com.mytv.launcher/files/logs/launcher-errors.log` |
| السجل السابق عند امتلاء الملف | `Android/data/com.mytv.launcher/files/logs/launcher-errors-previous.log` |
| نسخة سهلة للمشاركة | `Download/MyTVLauncher-errors-YYYYMMDD-HHMMSS.log` |
| أخطاء مسجلة | انهيارات Java غير المعالجة، أخطاء تحميل WebView، أخطاء JavaScript وReact، ورسائل console من المستوى Error أو Warning، وأخطاء الخلفية والإشعارات الأساسية. |

## طريقة جمع السجل

بعد تثبيت التطبيق وظهور المشكلة، افتح **Launcher settings** ثم اختر **Export diagnostic log**. سيحفظ التطبيق نسخة في مجلد **Download** حتى يمكن نقلها إلى USB أو إرفاقها في رسالة لاحقة.

إذا انهار التطبيق قبل الوصول إلى الإعدادات، افتح مدير الملفات في الرسيفر وانتقل إلى مسار `Android/data/com.mytv.launcher/files/logs/` وانسخ الملفين الموجودين هناك إن وُجدا. يجب تصدير السجل قبل إزالة التطبيق، لأن Android قد يحذف مساحة التطبيق الخاصة عند إزالة التطبيق.

يمكن استخدام زر **Clear diagnostic log** بعد إرسال السجل لبدء اختبار جديد بسجل نظيف.
